Análisis de mercado tiene 33 (Base de datos 2025/2026, Benchmark, Identificacion_Unidades_Ingresos_2026, Ingresos_Llegate_9, Manual_Costos_Llegate, Ficha_Propietario_Negociacion, Avatar_Propietario_UNIFICADO, Inventario maestro, Análisis Interno v8, notas del libro 500.000 seguidores…)
